# Level Decision Record Template

Use this record for decisions that materially shape structure, use, gameplay, composition, or style. Do not create a record for every minor prop or reversible placement.

```text
Decision ID and title:
Date / candidate version:
Status: Proposed / Approved for Phase / Superseded / Reopened / Rejected

Decision:
Reasoning:
Affected zone:
Gameplay impact:
Reality / reference relationship:
Deliberate departure from reality:
Why the departure improves the game:

Accountable role:
Consulted roles:
Human decision required: yes / no — reason
Evidence used:
Authoritative sources:

Open risks:
Validation phase and pass condition:
Supersedes / superseded by:
```

## Recording Rule

Create or update a record when a decision changes zone function, adjacency, routes, scale, spawn or encounter logic, landmark hierarchy, density strategy, boundary treatment, environmental story, material/light direction, asset-family strategy, or a deliberate realism adaptation. Link the record from the phase evidence manifest and retain superseded decisions rather than silently rewriting history.
