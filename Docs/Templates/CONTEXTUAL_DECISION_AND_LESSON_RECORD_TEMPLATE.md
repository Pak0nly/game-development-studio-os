# Contextual Decision and Lesson Record Template

> **Status:** Adopted through LAIA-2026-07-22 on 2026-07-22. Using a record does not itself grant permission or execution authority.

Use this compact record for a verified production lesson, contextual rejection, or superseded decision that may matter again. It is evidence-backed project context, not a new Studio OS rule.

```text
ID and title:
Tags (execution mode and subject):
Trigger:
Verified cause:
Validated response:
Invalid shortcut:
Applies to:
Does not apply to:
Current status: Active / Accepted Concern / Superseded / Closed / Needs Revalidation
Supersedes or successor:
Authority and evidence:
```

Load a record only when its tags, scope, and subject match the task. A Task-Delta Work Order lists applicable record IDs rather than copying the lesson. A superseded record remains traceable and points to its successor; it does not remain a binding rejection outside its stated scope.
