# Crime99 Capability Knowledge Base

This folder is the operational decision layer for tools, packages, asset
families and reusable workflows available to Crime99. It follows the Studio OS
[Tool and Asset Capability Knowledge Base Standard](../../../Knowledge/TOOL_AND_ASSET_CAPABILITY_KNOWLEDGE_BASE_STANDARD.md).

Start with [CAPABILITY_INDEX.md](CAPABILITY_INDEX.md) and search the complete
[CAPABILITY_COVERAGE_REGISTER.md](CAPABILITY_COVERAGE_REGISTER.md) by the
current problem and intended use. Open only the detailed records relevant to
the current decision.

For a park, plaza, garden, green buffer, waterfront open space or stormwater
landscape, also start with the problem-oriented
[Park Element Reference](PARK_ELEMENT_REFERENCE.md). It routes every park
function through a curated URP-first shortlist, separates unqualified but
relevant assets from current options, and explicitly excludes military,
industrial and other filename false positives from the default park pool.

For every material Unity task, also search the
[Unity Native Capability Atlas](Capabilities/C99-CAP-UNITY-NATIVE-ATLAS-001.md).
It exposes built-in Editor tools, engine APIs, official packages, installed
modules, diagnostics and known optional-package absences before custom work or
a new dependency is considered.

The Knowledge Base complements rather than replaces:

- [ASSET_INVENTORY.md](../ASSET_INVENTORY.md) for ownership, acquisition,
  provenance and broad holdings;
- local package/source files for exact installed capability;
- task evidence for exact technical, runtime and visual outcomes; and
- accepted project documents for adoption and production direction.

Current records were seeded from fresh local evidence on 2026-08-22. No Unity
execution, package change, download, adoption or source mutation was performed
to create them.

The coverage register, not the number of detailed record files, determines
whether known holdings are completely classified. A local holding may use one
aggregate record when that keeps the decision surface readable, but it may not
be omitted. External account completeness is reported separately. It is
`CURRENT ACCOUNT VERIFIED: 45 Assets / 0 UPM Packages` as of 2026-08-22 and
becomes stale when account holdings change or a later refresh supersedes it.

## Broad Static Discovery Source

The local [Asset, Tooling and Package Capability Catalogue V1](../../../../Projects/Crime99/Artifacts/Reports/C99-ASSET-TOOLING-AND-PACKAGE-CAPABILITY-CATALOG-V1/FINAL_REPORT.md)
is the broad static discovery source for the currently scanned project roots.
Its machine index covers exact file identities and its companion reports cover
major tools, workflows, asset families and vendor/demo scenes. Its snapshot is
dated 2026-08-10 and proves presence/static declarations only; runtime, visual
fit and adoption remain unknown unless a decision-ready record cites newer
evidence. Use it to discover a relevant holding, then consolidate only the
small decision-relevant subset into this Knowledge Base.
