## What this simulation can and cannot tell

- It can tell which drawings win when everybody plays the same simple way: run at the nearest opponent, try to push outward, back off near the edge, dash by chance. It shows whether the numbers make one stat profile win every exchange.
- It cannot tell how the game feels, and it cannot find tricks. Bots never dodge, bait, wait, gang up on purpose or aim a blade; they do not redraw between rounds and do not use catch-up ink. A human with a fast light drawing will play very differently from this bot.
- Many pairings are close to 0 or 100 percent because both bots repeat the same behaviour; the seeds only change start sides, wobble and dash timing. Read the averages as a ranking under one play style, not as odds between humans.
- The archetype field is hand-made. The numbers were tuned against exactly this field, so a drawing outside it may break the balance.
